# Leads folder rules

These rules apply to this folder only.

1. **These are made-up practice people.** Everyone in `leads.csv` is invented for practice. None of them is a real person.
2. **Never add real people or real email addresses.** Only add made-up people, and only with an `@example.com` address.
3. **Every row needs a consent value.** Don't add a row with an empty `consent` column. If you don't know how someone agreed to hear from us, don't add them.
4. **Never change the `@example.com` addresses.** That domain is reserved and can never receive mail, so no one is ever emailed by mistake. Don't swap it for any other domain.
